Detailed explanation of the files in the git:
```
├── ArrayAmpSliceHeight.py                           -> Main function of the code. Contains a python class to optimize the heights of a grid of transducers while keeping the phase to 0 for all the emitters in the grid. This heights are trained to generate an acoustic pattern at a desired height.
├── Waves.py                                         -> Contains helper functions used throughout the main code. These functions encapsulate common operations such as gneerate a planeGrid, generate normals for the phased array, compute the propagators to calculate the simulated acoustic fields.
├── ImageUtils.py                                    -> Contains functions used to load the images of the desired target pattern to optimize.
├── TestArrayAmpSliceHeight.py                       -> Main executable for ArrayAmpSliceHeight.py. It computes the idea heights for the 3 patterns presented in the paper.
├── TestArrayAmpSliceHeight_ForMNIST10.py            -> Similar to TestArrayAmpSliceHeight.py but used for Figure 4 and 5 of the paper. This code compares the proposed method in the paper against existance method such as Phased optimization. The patterns used to compare are extracted from MNIST10 dataset. 
├── PatternMeasurements.py                           -> Code used to take experimental measurements. It is designed to serally connect to a delta printer (BIQU Kossel9 Plus) and to a PicoScope2004A Series (attached to the tip of the printer). The extruder will be moved in a sqaure grid to take measuremnt of the acoustic field in each step.
├── UtilsMeasurement.py                              -> Contains helper function to both connect to the printer and to the PicoScope.
├── VisualizeMeasurement.py                          -> Code that can be executed to visually check the measurement taken.
├── CreatePlateFromEmitters.py                       -> Generates a mesh to transform into an STL with the heights of the transducers computed by the algorithm proposed in this paper.
├── results                                          -> Result obtained in the paper. ** stands for the specific pattern depicted in each image (i.e., a star shape, the letter A, or the number 12).                         
    ├── Experiment_VS_Simulation_HeightMod_**.png    
    ├── sim_**.png                                   
    ├── meshes                                       -> Mesh generated by CreatePlateFromEmitters.py. This files can be used to generate the metasurfaces used in the paper.
        └── Mesh_heightMod_**.scad                   
    └── STLs                                         -> STLs for the 3D printing the metasurfaces.
        └── STL_heightMod_**.stl
├── measurements                                    -> Directory used to store all the experimental data produced by the paper.
    ├── GenerateImageExpAndSim.py                   -> Code used to generate the images to produce Figure 3 in the article.
    ├── target_**.png
    ├── sim_**.png
    ├── experHeightMod_**.png
    ├── ExperimentalData_HeightMod                  -> Experimental data recorded by the PicoScope each csv in a 128x128 grid of values obtained from the experiments.
        └── HeightMod_**.csv
    └── Simulations                                 -> Simulations used to compare against the experimental data. Each csv has 256 rows where each row provides information about the transducer in the phased array. the file format is: x,y,z,nx,ny,nz,power,frequency,apperture,Type(0=circle,1=square),sx,sy,sz,phase.
        ├── heightMod_**.csv
        └── VisualizeDataFromCsv.py
├── patterns                                        -> This directory contains the images of the patterns used in the paper. This patterns included a star shape, the letter A, the number 12 and 10 random images from MNIST 10 dataset.
│   ├── 12.png
│   ├── A.png
│   ├── star.png
│   ├── mnist10
│   │   ├── Label_0.jpeg
│   │   └── ...
└── results_MNIST10                                -> Stored the results for evaluating and comparing the different optimization methods against the model discussed in the paper.
    └── ...
└── paper photos                                   -> Includes photos taken for the paper and the figures used in the latter.
    └── ...
```
